# How to Read Odds / Odds कैसे पढ़ें

## English
Decimal odds show how much return you may get if your bet wins.

Example:

```text
Odds = 1.85
Stake = ₹100
Potential return = ₹100 × 1.85 = ₹185
Profit = ₹85
```

Higher odds mean higher risk and higher possible return. Lower odds mean the bookmaker thinks that result is more likely.

## Hindi
Decimal odds बताते हैं कि bet जीतने पर कितना return मिल सकता है।

Example:

```text
Odds = 1.85
Stake = ₹100
Potential return = ₹100 × 1.85 = ₹185
Profit = ₹85
```

High odds का मतलब usually ज्यादा risk होता है। Low odds का मतलब bookmaker उस result को ज्यादा possible मानता है।
